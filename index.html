Choose an operation to see only the faces it made. The colours come from provenance: every operation reports what it generated, modified and deleted, and a tag put on faces follows them through every later operation.

Try it

pip install arris

Prebuilt wheels for Linux, macOS and Windows, with no Rust toolchain needed. From Rust, cargo add arris.

What sets it apart

  • Every operation says what it did. Provenance lets a script pick “the edge the extrude made” instead of an index that shifts when the model changes.
  • It refuses rather than guesses. Geometry it cannot do is a typed error naming the entities, never a panic or an invalid shape.
  • Deterministic. Same input, same ids, on every platform; a wasm32 body is byte-identical to the native one.
  • Pure Rust. No unsafe, no C++ underneath. Open CASCADE is run as the test oracle, never linked.
